# Zapret Setup Guide

## Кратко

1. Запустите файл **service.bat**.
2. Выберите пункт **9. Update hosts file**.
3. Перед вами появится файл **zapret_hosts.txt**.
4. Скопируйте его содержимое.
5. Скопируйте айпишники из прикрепленного файла **ip.txt**.
6. Запустите приложение **Блокнот** от имени администратора.
7. В меню выберите **Файл → Открыть** и перейдите по пути: `C:\Windows\System32\drivers\etc\hosts`.
8. Вставьте всё, что скопировали, в конец файла.
9. Сохраните файл **hosts**.
